# Функциональные требования — аналог wPlace

## 1. Управление холстом

| ID | Требование |
|----|-----------|
| FR-1.1 | Система должна предоставлять общий холст фиксированного размера (N×M пикселей), доступный всем подключённым пользователям одновременно. |
| FR-1.2 | Каждый пиксель холста должен хранить цвет (из заданной палитры) и информацию о последнем пользователе, установившем его. |
| FR-1.3 | Система должна поддерживать настраиваемую цветовую палитру (не менее 16 цветов). |
| FR-1.4 | Состояние холста должно сохраняться на сервере и восстанавливаться при перезапуске. |

## 2. Размещение пикселей

| ID | Требование |
|----|-----------|
| FR-2.1 | Авторизованный пользователь должен иметь возможность установить один пиксель выбранного цвета в заданную координату холста. |
| FR-2.2 | После установки пикселя система должна заблокировать возможность повторной установки для данного пользователя на настраиваемый период (кулдаун: час / минута / день). |
| FR-2.3 | При попытке установить пиксель во время активного кулдауна сервер должен отклонить запрос и вернуть клиенту оставшееся время ожидания. |
| FR-2.4 | Сервер должен валидировать координаты пикселя (в пределах холста) и выбранный цвет (из допустимой палитры). |

## 3. Регистрация и аутентификация

| ID | Требование |
|----|-----------|
| FR-3.1 | Система должна поддерживать регистрацию нового пользователя по логину и паролю. |
| FR-3.2 | Система должна поддерживать аутентификацию пользователя по логину и паролю. |
| FR-3.3 | Сервер должен выдавать сессионный токен при успешной аутентификации; все последующие запросы клиента должны содержать этот токен. |
| FR-3.4 | Система должна отклонять запросы на размещение пикселей от неаутентифицированных пользователей. |

## 4. Синхронизация

| ID | Требование |
|----|-----------|
| FR-4.1 | При установке пикселя любым пользователем сервер должен рассылать обновление всем подключённым клиентам. |
| FR-4.2 | При подключении нового клиента сервер должен передать ему актуальное состояние всего холста. |
| FR-4.3 | Сервер должен отображать количество подключённых пользователей онлайн и транслировать это значение клиентам. |

## 5. Клиент

| ID | Требование |
|----|-----------|
| FR-5.1 | Клиент должен отображать холст в графическом интерфейсе с возможностью масштабирования и навигации. |
| FR-5.2 | Клиент должен предоставлять панель выбора цвета из доступной палитры. |
| FR-5.3 | Клиент должен позволять пользователю установить пиксель кликом по нужной позиции на холсте. |
| FR-5.4 | Клиент должен отображать таймер кулдауна после размещения пикселя. |
| FR-5.5 | Клиент должен предоставлять экраны входа и регистрации. |
